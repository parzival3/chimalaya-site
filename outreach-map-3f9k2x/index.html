Chimalaya outreach map preview

The red marker shows the Chimalaya Charity clinic; blue markers show health posts with locations supplied for this preview.

Opening this as a local file can cause OpenStreetMap to return 403. From the project folder, run python -m http.server 8000, then open http://localhost:8000/output/Chimalaya_Health_Post_Map_Demo.html.

    Pulses identify the Chimalaya Charity clinic and mapped health posts; they do not represent distance travelled or programme growth over time. Event figures are recorded attendances, not unique people. Map © OpenStreetMap contributors.
